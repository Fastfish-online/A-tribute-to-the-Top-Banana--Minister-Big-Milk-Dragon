# OpenCV 第二次作业完成说明

本作业的图像处理统一使用黄色卡通角色图片，视频处理使用黄色卡通角色动态视频。运行结果保存在 `output` 文件夹。

## 任务一完成情况

`output` 中包含以下三张必需结果：

- `task1_gray.png`：灰度图。
- `task1_canvas.png`：包含直线、矩形、圆、椭圆、多边形和英文文字的黑色画布图。
- `task1_annotated.png`：带检测框、类别名和置信度数字的原图。

程序可以正常打开彩色图、灰度图和绘图画布窗口。按下任意键后，所有窗口会正常关闭。检测框和 `character 0.80` 文字均位于画面范围内，没有超出图片边界。

## 任务二完成情况

输入视频为 `images/sample.avi`，内容是黄色卡通角色动态视频。处理结果保存为 `output/task2.avi`。

输入视频和输出视频的画面尺寸均为 108×144，帧率均为 20 FPS，共 86 帧。输出视频左上角可以看到当前帧号，播放时按 `q` 可以提前退出。

正常情况下直接使用视频读取到的 FPS。若读取到的 FPS 小于等于 0 或明显异常，则使用 25 FPS 作为备用正数，避免 VideoWriter 因无效帧率而无法创建视频；这一点已在任务二代码注释中说明。

## 任务三完成情况

已保存 ROI 粘贴结果、B/G/R 三通道图、通道调整图、常数边框、反射边框、NumPy 加法、OpenCV 饱和加法、加权混合和圆形掩膜结果。终端会输出图像属性、修改前后的像素值以及双重循环与整图操作的耗时。

## 任务四完成情况

已保存颜色 mask、缩小、放大、平移、旋转、透视变换、四种阈值、四种平滑以及腐蚀、膨胀、开运算、闭运算结果。

本图最后更适合使用开运算去除噪点。原因是黄色区域的 mask 中主要问题是零散的白色前景噪点；开运算先腐蚀再膨胀，可以去掉这些小白点，同时尽量保留主体。闭运算主要用于填补前景内部的小黑洞，不是本图最主要的噪声问题。

## 任务五完成情况

### Canny 边缘

高斯模糊后分别使用 40/100 和 100/200 两套高低阈值，并保存两张结果。

本图中 100/200 的结果更干净。它过滤了更多由压缩纹理和亮度轻微变化产生的弱边缘，保留下来的角色主体边缘更明确；40/100 能检测到更多细节，但杂乱的弱边缘也更多。

### 图像金字塔

原图尺寸为 408×544。第一次 pyrDown 后为 204×272，第二次 pyrDown 后为 102×136；随后对第二层执行一次 pyrUp，结果回到 204×272。

与原图相比，pyrUp 后的图像仍只有原图一半的宽和高，而且边缘更柔和、细小纹理更少。原因是两次降采样已经丢失高频细节，之后再放大只能插值，无法恢复原来的清晰度和细节。

### 轮廓

`task5_contours.png` 是唯一的轮廓标注结果图：灰色表示全部轮廓，黄色表示面积大于 500 的轮廓，红色表示最大轮廓的正外接矩形，蓝色表示最大轮廓的最小外接矩形，图中同时标出了最大轮廓面积。

`task5_contour_binary.png` 是轮廓检测使用的二值输入图，不是另一张轮廓标注图。
